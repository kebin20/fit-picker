# Outfit quality study 01

A single-outfit visual test following the inZOI / professional fashion-render research. Built-in ImageGen was used with the four existing garment photographs as appearance references. The exact prompt is in `prompt.txt`.

The generated board shows the same hypothetical adult model from front, side and back in the navy shirt, open solid brown overshirt, grey slacks and all-black sneakers. Review the silhouette, shoulders, sleeve/hem lengths, fabric folds and footwear together before expanding the wardrobe.

This is generated concept imagery, not a CLO/Marvelous Designer simulation, an exported 3D mesh, a scan of the owned clothes or a prediction of personal fit. Side/back construction details are inferred because the references show the garments from the front. The main app preview is unchanged.

The original generated PNG is `navy-after-hours-three-views.png`. The web-optimized board is `public/previews/navy-after-hours-quality-v1.webp`; a standalone, dependency-free review page lives at `/previews/navy-after-hours.html` and switches between the complete board and each view using CSS framing.
