# Useful next steps for Kevin

Keep the app centred on one person's wardrobe. These are suggestions, not features included in the current release.

1. **Saved-look backup and restore.** Export/import a small JSON file, with validation and merge/replace choices. Current favourites only live in one browser; this also makes moving between phone and desktop practical without starting an account system.
2. **Worn recently.** A one-tap “Wore this” action and date, with optional fewer-repeats ordering. Keep history local initially.
3. **Laundry and unavailable pieces.** Hide suggestions containing a piece in the wash, being repaired or packed away. Leave the inventory intact.
4. **Build around one item.** Lock the trousers or shoes you want to wear, then filter compatible outfit suggestions around that piece.
5. **Hide a suggestion / pin favourites.** Personal feedback is more valuable here than adding hundreds of near-identical combinations. Let Kevin undo hidden items and reset this preference.
6. **Temperature and rain.** Start with a manual temperature range and rain toggle so clothing advice remains usable without location permission or another network service. Weather lookup can stay optional.
7. **A short packing list.** Pick a season, occasions and a few favourite outfits; deduplicate their clothes into a checklist.

For phone use, retain 2D as the default, load 3D only on request, and avoid automatic turntable animation. Use responsive pre-generated photos rather than runtime AI generation. If offline installation is added later, cache a small shell and chosen favourites, not the entire image/model collection.
