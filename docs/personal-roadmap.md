# Personal wardrobe roadmap

Implemented in v0.8.0:

- Lock selected pieces when filtering recommendations.
- Laundry/unavailable status; unavailable clothes are excluded from recommendations.
- Local wear history, fewer recent repeats, pinned favourites and hidden suggestions.
- Manual temperature/rain filtering with editable warmth and rain suitability.
- Persistent current outfit, occasion/season, locks and preferences.
- Rename/update saved outfits, prevent duplicate saves and undo deletion.
- Validated export/import backup with a replacement preview, storage rollback and undo restore until reload.
- Add/edit wardrobe pieces with resized local photos, colour, garment type, seasons, warmth and notes.
- Explicit offline caching of chosen outfit photos plus the small app shell, with 2D offline viewing.
- Clear wardrobe searches when opening the studio; soften 3D wrinkle shading.

Possible later additions: automatic cross-device sync, packing checklists and richer outfit history summaries. Current backup transfer is manual; these features remain local to one browser. New wardrobe pieces can be built into and saved as outfits; curated recommendations continue to use the original wardrobe library and weather variations.
